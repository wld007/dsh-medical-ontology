模型扮演数字病人
结局预测（世界模型）
病人接下来会怎样，包括下一次主线治疗决定何时、因何出现。这里的“结局”指方案之后观察到的变化，包括短期变化，不限于终局；只问发生了什么，不问是不是这次治疗造成的，后者由 T08 结局归因来考。
T01
病人接下来会怎样
参考答案：病历记录
考什么
世界模型能力：给出一次治疗方案，预测这位病人之后的真实变化。
给模型什么
截至本次方案当天的病程（此前每次治疗方案、之后已获知的变化、期间检查与评估的结果）＋本次方案。
要它答什么
方案后 0–90 天的变化与疗效概率（好转 / 稳定 / 进展）；下一个主线治疗决策的原因类别概率与距今天数（点估计＋80% 区间）；91–180 天、180 天以后的变化。
参考答案从哪来
临床本体中该治疗节点之后 0–90 天、91–180 天、180 天以上的结局记录；下一个主线治疗决策的天数为到下一个主线治疗节点的间隔（跳过检查节点），原因取自该节点记录的临床问题。
怎么计分
疗效类别命中；原因类别首位与前两位命中；天数区间是否覆盖真实值、点估计误差。均与“用其余病人的统计作答”的朴素参照对比。
防泄漏与口径
只按写进病历的时间截断；指向本题之后的衔接信息一律隐去；原因类别由规则判定，并经人工核对。

T02
截至第 k 天
参考答案：病历记录
考什么
时间推理与校准：在不同时间跨度上，事情发生了没有，概率给得准不准。
给模型什么
同 T01 的病程与本次方案，外加一个随机时点：方案后第 k 天（7–365 天，按对数均匀抽取）。
要它答什么
子任务 H1：截至该日下一个主线治疗决策是否已出现（概率）、若已出现在第几天、原因类别；子任务 H2：截至该日已经发生了哪些变化。
参考答案从哪来
H1 由下一个主线治疗节点的日期直接算出；H2 取本节点结局记录中日期不晚于第 k 天的部分。
怎么计分
H1 看判对率与 Brier 分数，按 ≤30 / 31–90 / 91–180 / 180 天以上分段报告；H2 看要点召回，由评审打分。
防泄漏与口径
抽样随机种子固定；H2 只取不跨越下一个主线治疗节点的时点。

T03
开环推演
参考答案：病历记录
考什么
长时程一致性：只给每一步的治疗方案，模型要靠自己前面的预测一路推下去。
给模型什么
系统提示词＋每一步的治疗方案；模型每一步的输出作为下一步的历史，不给任何真实结果。
要它答什么
每一步都按 T01 的格式作答。
参考答案从哪来
每一步的参考答案同 T01。
怎么计分
逐步按 T01 计分，并与“每步都给真实历史”的 T01 相比，看掉了多少分；每条病程重复推演 3 次，看稳定性。
防泄漏与口径
整条病程只出现治疗方案；检查结果不给，由模型自行推断。
作答形式
同 T01，多步连续
看一道样例

加用培美曲塞＋卡铂＋贝伐珠单抗
每一步预测此后的变化；前一步的预测作为下一步的历史，不给任何真实结果。

临床决策（策略）

T04
医生下一步会怎么做
参考答案：病历记录
考什么
策略能力：与 T01 合成完整的“状态 → 动作 → 下一状态”。预测的是这家医院真实会怎么做，不是教科书上的最优解。
给模型什么
截至今天的病程，不含今天的决定。病程里“为什么进入下一步”的衔接说明一律隐去，避免泄露今天的决定。
要它答什么
8 类动作的概率：启动或更换方案 / 继续原方案 / 调整原方案 / 加局部治疗 / 停止或转支持 / 处理合并症或不良反应 / 先检查或取材 / 转科转院；具体措施（药名或操作名）；理由。
参考答案从哪来
该节点记录的决策原文与实际执行情况（执行状态、首次执行日）。检查节点也出题：“先检查再定”本身就是一个决定。
怎么计分
动作类别命中；具体措施 F1（按通用名归一）；因缺药、费用、病人拒绝等非临床因素做出的决定单独报告。
防泄漏与口径
不给该节点记录的临床问题原文，因为它常常已经写出了答案，例如“需更换为三代 TKI”。

T10
并行治疗对主线的影响
参考答案：加工判断，需医生复核
考什么
多问题并行管理：抗肿瘤主线之外出现的新问题（毒性、感染、合并症等）怎么处理，处理之后抗肿瘤主线要做什么调整，对应临床上的暂停给药、减量、停药。
给模型什么
截至新问题出现当天的病程（衔接说明隐去）＋新问题描述＋当前的抗肿瘤主线方案。
要它答什么
并行治疗决策与结局；处理之后抗肿瘤主线实际怎样（不受影响 / 暂停后恢复 / 减量或降级 / 提前换线 / 中止）；理由。
参考答案从哪来
临床本体中标注的伴发事件：主线决策 → 其他治疗方向出现的问题 → 并行治疗决策 → 结局 → 对主线的影响。
怎么计分
“对主线的影响”五分类准确率；并行治疗决策与结局的要点由评审打分。
防泄漏与口径
这类关系经医生复核确认后才作为参考答案；只出主线之外的问题，抗肿瘤主线内部的前后衔接不出题（由 T01 考）。

T07
状态追踪与诊断归类
参考答案：病历记录＋加工归类
考什么
长病程状态追踪：某一天在用什么治疗；每个诊断是肺癌本身、转移引起、治疗引起，还是独立的共病。
给模型什么
截至某日的病程＋一份诊断清单（名称与首次出现时间）。
要它答什么
当前的抗肿瘤治疗；每个诊断的角色（主诊断 / 继发 / 不良事件 / 共病）与确定程度（确诊 / 临床诊断 / 疑似 / 待定）。
参考答案从哪来
临床本体疾病层的角色与确定程度判据；当前治疗取截至该日最近的主线治疗节点。
怎么计分
当前治疗集合 F1；角色与确定程度的分类准确率，“不良事件还是共病”单独报告。
防泄漏与口径
确定程度随时间变化的（如先写“？请结合临床”、后来明确），按该日之前的记录判定。

T08
结局归因
参考答案：加工判断，需医生复核
考什么
长时程信用分配：一个结局有多少该算在某次治疗头上，混杂因素有哪些，能不能分开。
给模型什么
截至结局出现后的病程＋被归因的治疗＋观察到的结局。
要它答什么
份额（列了几项治疗就逐项给：主要 / 部分 / 微小 / 无 / 不可判定）；可分离性（可分离 / 部分可分离 / 不可分离）；混杂因素类别（多选）；理由。
参考答案从哪来
临床本体的结局归因表：每条治疗链、每个时间尺度一行。
怎么计分
份额逐项按有序等级计分，每差一级扣 1/3，“不可判定”须完全一致；可分离性每差一级扣一半；混杂因素与理由不计分。
防泄漏与口径
参考答案是定性判断，不是观察到的事实，经医生复核后使用。
作答形式
有序分类
多选
看一道样例
化疗后骨髓抑制
题面
被归因的治疗

参考答案

T05
该说“不知道”
参考答案：病历记录
考什么
证据不足时的克制：记录里没有、或超出数据范围时，能不能说“无法判断”，而不是用常识编一个。
给模型什么
截至某日的病程；需要时附数据记录范围（末次接触日）。
要它答什么
是 / 否 / 无法判断三个选项的概率，以及依据。
参考答案从哪来
按规则出三种题：问题超出末次接触日（应答无法判断）；检验项目被点名却没有结果（应答无法判断）；病程中有明确记录的事实（应答是或否，作对照）。
怎么计分
三分类准确率；“无法判断”的精确率与召回率；Brier 分数。三种题数量大致均衡，一律答“不知道”拿不到高分。
防泄漏与口径
系统提示词写明“没写不等于没发生，数据结束不等于治疗结束或死亡”；对照题必须能在给出的病程里找到依据。
作答形式
三分类概率
看一道样例
超出记录范围
题面
D+2761
培美曲塞＋卡铂化疗
D+2769
化疗后骨髓抑制，予升白治疗
D+2784
末次接触，此后没有任何记录
D+2904 时，这位病人是否仍在接受抗肿瘤治疗？
参考答案
无法判断
末次接触为 D+2784，此后没有记录；数据终止不等于治疗终止
T06
医生当时知不知道
参考答案：病历记录
考什么
时间卫生：区分“事情发生的时间”和“写进病历的时间”，后来写下的回顾不能当作更早那天的依据。
给模型什么
若干条记录片段（各带写成日期）＋一个决策日。
要它答什么
每条信息在决策日能否作为依据（是 / 否），以及理由。
参考答案从哪来
临床本体为每个事件记下首次写进病历的时间，与事件发生日期分开记录。
怎么计分
逐条判对率；重点看“事件早、写入晚”的那类有没有被误判为可用。
防泄漏与口径
片段原文照录，只做日期相对化；同一事实出现在多份记录时，以最早写入的为准。
作答形式
逐条是 / 否
看一道样例
决策日 D+1334
题面
①
写成于 D+421：予克唑替尼靶向治疗
②
写成于 D+488：放疗科住院，出院诊断含药物性肝炎
③
写成于 D+605：住院，出院诊断含放射性肺炎
④
写成于 D+1728：回顾病史“约 D+643 停用克唑替尼，改口服依托泊苷”
站在 D+1334，每条记录里的信息能否作为当时的依据？
参考答案
①②③ 可用：写成日期都不晚于 D+1334
④ 不可用：事件发生在 D+643，但写进病历是 D+1728，晚于决策日
T09
找矛盾

病历可靠性：区分真冲突、看似矛盾实则不冲突、可以裁决三种情况，不一律“取最新”。
给模型什么
同一病人在同一件事上的 2–3 条记录，带日期与来源类别。
要它答什么
关系类别（真冲突 / 不冲突 / 可以裁决）；可以裁决时以哪条为准；理由。
参考答案从哪来
临床本体的冲突登记（时间线冲突、口径不一致、多源冲突），并收入已有定论、不冲突的条目作反例。
怎么计分
三分类准确率；真冲突的召回率。
防泄漏与口径
只收登记中给出两条以上原文的条目；三类题数量保持大致均衡。
